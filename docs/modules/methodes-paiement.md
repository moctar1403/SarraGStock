# Configuration : Méthodes de Paiement

[⬅ Retour au sommaire](/documentation/user_guide)

Pour configurer vos moyens de paiement, allez dans **Configurations > Méthodes de paiement**. 
C'est ici que vous gérez les caisses et les comptes par lesquels l'argent entre et sort de votre entreprise (Espèces, Bankily, Crédit, etc.).

![Liste des méthodes de paiement](/images/docs/liste-methodes.png)

---

## 1. Comprendre le tableau

Le tableau vous donne une vue d'ensemble de la santé financière de chaque méthode :
- **Nom** : Le nom de la méthode (Espèce, Crédit, Bankily...).
- **Téléphone** : Le numéro de téléphone associé (si applicable).
- **Active** : Un badge vert "Oui" indique que la méthode est utilisable lors des ventes. Un badge rouge "Non" signifie qu'elle est désactivée.
- **Solde réel** : C'est l'argent physique actuellement disponible dans cette caisse ou sur ce compte.
- **Solde des ventes** : C'est le cumul de l'argent généré par les ventes sur cette méthode.

---

## 2. Ajouter une méthode de paiement

Cliquez sur le bouton bleu **Ajouter une méthode de paiement**.

![Créer une méthode de paiement](/images/docs/creation-methode.png)

Remplissez le formulaire :
- **Nom** *(Obligatoire)* : Le nom de la méthode (ex: "Bankily").
- **Téléphone** *(Obligatoire)* : Le numéro associé. **Il doit contenir exactement 8 chiffres**.
- **Active** : Cochez cette case pour que la méthode soit disponible immédiatement.

*(Note : Le nom de la méthode doit être unique).*

---

## 3. Modifier ou Supprimer (⚠️ Règles de sécurité)

⚠️ **Attention : Toutes les méthodes ne sont pas modifiables ni supprimables.**

L'application possède des **méthodes de base** qui sont protégées pour garantir l'intégrité de votre comptabilité. Vous ne pouvez pas modifier les boutons des méthodes de base.

- **Modification** : Vous ne pouvez modifier que les méthodes que vous avez créées vous-même (celles avec un ID supérieur à 2). La méthode "Espèce" (ID 1) et "Crédit" (ID 2) ne sont pas modifiables.
- **Suppression** : Vous ne pouvez supprimer que les méthodes que vous avez créées (celles avec un ID supérieur à 5). Les méthodes prédéfinies dans l'application ne peuvent pas être supprimées.

*Pour les méthodes personnalisées, cliquez sur le bouton violet **Modifier** ou rouge **Supprimer**.*
