# Journal des Mouvements de Stock

[⬅ Retour au sommaire](/documentation/user_guide)

Ce journal est le "Grand Livre" de votre stock. Il enregistre absolument tous les mouvements physiques de vos articles (entrées, sorties, ventes, pertes).

---

## 1. Consulter le journal

1. Allez dans le menu **Journal Mouvements** (ou depuis le menu Opérations).
2. Vous verrez un tableau avec :
   - **Date** : Quand le mouvement a eu lieu.
   - **Type** : Vente, Perte, Entrée, Détail, etc. (les entrées sont en vert, les sorties en rouge).
   - **Article** : Le nom de l'article concerné.
   - **Quantité** : La quantité ajoutée (+) ou retirée (-).
   - **Référence** : Le numéro de facture ou d'opération.
   - **Utilisateur** : Qui a effectué le mouvement.

---

## 2. Filtrer les mouvements

Vous pouvez filtrer par :
- **Date de début et de fin** (par défaut, le mois en cours).
- **Recherche par nom d'article**.
